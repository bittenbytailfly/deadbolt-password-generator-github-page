Generate a strong, memorable password

If you need a quick and easy password that's easy to remember or type in from a text message, this tool is for you.

How does it work?

This simple password generator creates a strong password using a pattern of words and numbers in a word.WORD.word!999 format.

Is it secure?

Passwords are generated on your computer, not the server, and they're not logged anywhere so only you see them. Since they use a common pattern, they are more susceptible to brute foce attacks, so these are best reserved for one off uses such as to password protect a zip file or create a password for a new user who will be prompted to change it on first use.
